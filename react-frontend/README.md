# LMS Portal — React frontend

See the top-level `README.md` for how to run the backend, mock API and frontend together.

Environment variables (optional, see `.env.example`):

- `VITE_API_URL` — Express backend, default `http://localhost:5000/api/v1`
- `VITE_MOCK_API_URL` — json-server mock API, default `http://localhost:5001`
